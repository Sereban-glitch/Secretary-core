# Secretary Core — независимый умный расшифровщик

Публичная чистая основа для внешнего агента. **Это стартовый модуль и ТЗ, не готовый сервис.** Нет зависимости от Telegram, AgroBot, его БД или секретов. Цель: аудио → точная расшифровка → отдельный структурированный черновик → проверка человеком → экспорт в любую базу знаний.

Начать с [задания агенту](AGENT_TASK.md), [контракта прокси](docs/PROXY.md) и [предыстории](docs/HISTORY.md).

## Сейчас реализовано
- Небольшой адаптер payload/response для прокси, без сетевых запросов и скрытых ключей.
- Офлайн-тесты в стандартной библиотеке Python 3.12+.
- Требования к изоляции, очереди, качеству и интеграции.

```sh
python3 -m unittest discover -s tests -v
```

## Планируемый интерфейс
Создать задание с локальным файлом → получить job_id → получать статус → забрать JSON и Markdown. Бот/админка только предоставляют файл, показывают прогресс и запрашивают публикацию. Модуль сам ничего не отправляет в Telegram и не пишет в базу заказчика.

Конфигурация указана в `.env.example`. Рабочий прокси приватный: доступ выдаёт владелец отдельно. Без него использовать fake transport; не заменять его прямыми платными API молча. Реальная расшифровка и интеграция пока не проверены. Лицензию на распространение отдельно определяет владелец; сейчас лицензия не назначена.
