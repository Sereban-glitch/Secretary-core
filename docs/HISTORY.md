# Предыстория

Владелец ранее делал Python-секретаря: скачать аудио, ffmpeg mono Opus 16k, сегменты по 15 минут, Gemini, промежуточный Markdown, отправка в Telegram. В архиве найдены четыре версии, статически просмотрены; они не запускались при подготовке этого проекта.

Полезно сохранить идеи последовательности, сегментации, промежуточных результатов. Не переносить дефекты: одна общая папка для всех заданий; повторное использование чужих старых сегментов; очистка чужой папки; пропуск неудачного сегмента с объявлением успеха; жёсткие имена спикеров; литературная перепись и обрезка хвоста; shell=True с URL; ключи в исходнике. Старый downloader отсутствует в прежнем месте.

Поэтому репозиторий создан с чистой историей, без копирования старых скриптов и разговоров. Это сознательное выделение независимого ядра, а не восстановление старого Telegram-бота. В AgroBot есть отдельная функция audio→Gemini, но модуль должен работать через прокси и не зависеть от AgroBot.
